# Локальные модели и роли

Проверенная конфигурация на 14 августа 2026 года.

## Mac mini: always-on слой

Фактическое железо: Apple M4, 16 ГБ unified memory. На Mac постоянно работает Ollama как Homebrew service.

| Роль | Модель | Размер | Причина |
|---|---|---:|---|
| Классификация запросов | `qwen3:1.7b` | 1.4 ГБ | После прогрева выбирает маршрут примерно за 1–2 секунды, не расходует подписки |
| Анализ фото и скриншотов | `qwen3-vl:2b` | 1.9 ГБ | Локальный vision для Emilia и ручных проверок |
| Локальный чат | `qwen3:4b` | 2.5 ГБ | Отвечает без расхода подписок и надёжнее следует русским инструкциям |
| Hermes с длинным контекстом | `amori-hermes:4b` | те же веса | Alias `qwen3:4b` с `num_ctx=65536`, отдельной копии весов нет |

```bash
brew services start ollama
ollama pull qwen3:1.7b
ollama pull qwen3-vl:2b
ollama pull qwen3:4b
ollama create amori-hermes:4b -f models/Modelfile.hermes
ollama list
```

`qwen3:1.7b` выбран только для скорости классификации, а не для ответов пользователю или самостоятельной работы с кодовой базой. Его решение проверяется детерминированными guardrails в `amori-ai`; локальные ответы выполняет `qwen3:4b`.

## MacBook 16 ГБ

Профиль MacBook использует отдельный alias `ami-qwen3:1.7b-nothink` для простых ответов и классификации. Он переиспользует веса 1.7B, отключает thinking в шаблоне и ограничивает Ollama-контекст до 8192 токенов. Лимит `context` в OpenCode сам по себе не ограничивает память Ollama, поэтому `num_ctx` задан в Modelfile. В живой проверке размер загруженного рантайма снизился с 5,2 до 2,2 ГБ.

```bash
ollama create ami-qwen3:1.7b-nothink -f models/qwen3-opencode-nothink.Modelfile
python3 scripts/configure-macbook.py --apply
opencode run --agent local-chat "Сколько будет 17 умножить на 6?"
```

Это быстрый, но небольшой помощник. Код, системные действия и сложный анализ должны идти через `ami` к Codex/Claude, а не выполняться моделью 1.7B. Установленные Qwen 9B и Gemma не удаляются; Gemma доступна отдельно как `local-deep`.

## Windows GPU: опциональный мощный слой

Windows-машина с RTX 4060 Ti 16 ГБ доступна по Tailscale только когда она включена. Там могут использоваться:

| Роль | Модель |
|---|---|
| Универсальный анализ | `qwen3.6:35b-a3b-q4_K_M` |
| Код и сложные задачи | `qwen3.6:27b-q4_K_M` |
| Быстрый чат | `gemma4:12b-it-qat` |

Windows не является обязательной частью маршрутизатора. При её отключении Mac продолжает классифицировать запросы и отвечать локально.

## Ограничения

- Полный Hermes загружает большой system prompt, skills index и schemas инструментов. На 4B это заметно медленнее прямого локального чата.
- Для реализации и тестов используется Codex CLI через ChatGPT OAuth.
- Для архитектуры и глубокого ревью используется Claude Code через Claude.ai OAuth.
- OpenRouter и другие API fallback не используются в целевой схеме, чтобы не создавать отдельную оплату за токены.
- Модельные теги всегда проверяются через `ollama show <model>` и `ollama list`, а не берутся из старой документации.

Проверка после перезагрузки:

```bash
brew services list | rg '^ollama'
curl -fsS http://127.0.0.1:11434/api/tags | jq -r '.models[].name'
amori-ai --doctor
```
