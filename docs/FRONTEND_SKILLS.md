# Frontend Skills Policy

Проверено 28 августа 2026 года для Codex, Claude Code, Hermes и OpenCode.

## Решение

| Источник | Статус | Роль |
|---|---|---|
| [Impeccable](https://github.com/pbakaus/impeccable) | включён глобально | основной frontend workflow: brief, режим поверхности, реализация, audit, hardening и bounded visual QA |
| [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | включён через `ui-design-research` | локальный поиск палитр, типографики, UX, charts и stack-specific рекомендаций |
| [Taste Skill](https://github.com/Leonxlnx/taste-skill) | не включён глобально | доступен только вручную через OpenCode SkillPointer для экспериментальной стилизации |

## Почему не установлены все три напрямую

`Impeccable` и `Taste Skill` оба претендуют на роль основного визуального директора.
Одновременная автоматическая активация создаёт конфликт обязательных правил, повышает расход
контекста и делает результат менее предсказуемым. Taste v2 дополнительно навязывает высокую
интенсивность motion и конкретные библиотеки даже там, где тихий рабочий интерфейс важнее
визуального эффекта.

`UI/UX Pro Max` ценен не как второй главный промпт, а как офлайн-база решений. Поэтому его
поисковые данные и Python-скрипты сохранены, но активация сужена до явного design research.

## Порядок применения

1. Явный запрос пользователя и существующие токены/компоненты проекта.
2. `impeccable` определяет режим: Persuade, Operate, Read или Experience.
3. `ui-design-research` вызывается только для выбора или сравнения дизайн-системы.
4. Реализация следует локальным правилам проекта и установленному стеку.
5. `screenshot-product-qa` подтверждает desktop/mobile результат скриншотами.

## Ограничения установки

- Глобальные Impeccable hooks отключены: обычные изменения файлов не получают скрытых
  дополнительных процессов.
- Browser extension и npm CLI не устанавливаются.
- UI/UX search выполняется локально и не требует сети или сторонних Python-пакетов.
- Taste Skill остаётся в OpenCode library, а не в активном shared-контексте.
- Upstream-коммиты и лицензии закреплены в папках skills для воспроизводимого обновления.

## Обновление

Обновление выполняется осознанно: скачать upstream во временную папку, проверить diff,
лицензию, команды и зависимости, обновить commit в `UPSTREAM.md`, прогнать smoke tests и
только затем выполнить `scripts/sync-skills.sh`.
